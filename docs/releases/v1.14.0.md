PS4 games are here: about 2,750 of them in the Library, installed and played with shadPS4, which
the launcher sets up for you. Settings is also reorganised so things are easy to find.

## Added
- **PS4 games:** the Library now lists RuTracker's PS4 releases next to the PS5 ones, each card
	marked **PS4** or **PS5**. Download and install them the same way; PS4 games run on
	**shadPS4**, which the launcher installs in the background and keeps up to date, like KytyPS5.
	PS4 games you already have as folders show up in your Library too.
- **PS4 PKG releases install:** most PS4 releases are PKG packages. The launcher unpacks the
	game, its update and its DLC for shadPS4 (it fetches a small PKG extractor the first time).
	PS5 PKG releases still can't be installed.
- **PS5 games only / PS4 games only:** two filter chips in the Library that combine with the
	others (for example **PS4 games only** + **In-game**). **All** clears every filter.
- **PS4 compatibility:** shadPS4's community results tag PS4 games (In-game, Menus, Boots…), and
	**Settings → Share your game ratings** sends your PS4 results to shadPS4's list.
- **PS4 controls:** while a PS4 game starts, and in **Settings → Controller & keyboard**, the
	launcher shows shadPS4's keyboard layout.

## Improved
- **Settings, reorganised:** Games, Playing, Downloads, Updates, Launcher and a folded-away
	Advanced section, in plain words. The launcher, KytyPS5 and shadPS4 updates sit together, each
	with its status, under one **Update automatically** switch.
- **Clean PS4 covers:** the blue PS4 band at the top of PS4 box art is cropped away.
- **Games only:** apps (YouTube, Media Player), system software and forum threads from
	RuTracker's PS4 section are left out of the Library.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
