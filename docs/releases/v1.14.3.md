A follow-up safety fix for installing PS4 PKG releases.

## Fixed
- **The write check always runs:** v1.14.2 added a guard that stops a PKG install when files
	can't be written completely. On some systems (a temporary folder that doesn't allow running
	programs) the guard could fail to load without anyone noticing, and the install went ahead
	unprotected. The guard now runs from the extractor's own folder, and an install is refused
	unless the guard confirms it's active.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
