New covers and game list fixes now arrive within the hour, and Call of Duty 4 is its own game again.

## Fixed
- **Game list updates arrive sooner.** The launcher used to check for a new game list only every
  6 hours, so fixes to names and covers could take most of a day to show up. It now checks at
  every start and every hour while it's open, and downloads the new list as soon as there is
  one. The check is a file under 1 KB.
- **Call of Duty 4: Modern Warfare (2007) is no longer filed under Modern Warfare 4.** The two
  names use the same words in a different order, so the older game took the new one's name and
  cover and showed up as a 6.6 GB "version" of it. Numbers in a name now have to match in place.
  Heroes of Might and Magic, which had been given Heroes III's details, is fixed too. This part
  comes with the game list, so it reaches every launcher version.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
