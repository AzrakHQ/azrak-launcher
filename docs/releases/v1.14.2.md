Two more safety fixes from review, and quieter update checks.

## Fixed
- **No truncated PS4 installs:** the PKG extractor ignored failed writes, so a full disk or a
	disk error could leave cut-off files behind and the game would still show as installed. The
	launcher now stops the extraction on any failed write, checks every file's size, and tells you
	why the install failed ("No space left on device", for example).
- **"Update automatically" Off means off:** an update found while you were playing could still
	install after your game closed, even if you had switched automatic updates off in the
	meantime. Now only updates you asked for install then.
- **No alarming errors offline:** the background update checks no longer show a red "Update
	check failed" in Settings when you're offline. A check you start yourself still tells you if it
	fails.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
