Downloads, Settings and the top bar are redesigned. A game now goes from download to Play in one go, and the launcher has no more pop-ups.

## New
- **Download & install in one step.** Download opens a panel beside the Game Hub: choose which
  files to get (a plain file list, a checkbox each) and where the download and the game go, with
  the free space on each drive. When the download finishes, the game installs by itself, and
  real problems (a release that can't be installed, not enough space) show on the file or drive
  they're about.
- **A new Downloads page.** Each download shows its key art and one bar running from download
  to install to Play. Filters: In progress, Needs you, Ready to play. **Delete…** asks what to
  remove: the download, the game, or both. **Share again** seeds a finished download. Installing
  never deletes what you downloaded.
- **Verifying.** Resuming a stopped download first checks what's already on disk. This now shows
  as **Verifying** in teal, with its own progress.
- **The top bar is one glass pill.** Downloads, Settings, battery and clock sit together. While
  something is happening, Downloads becomes a ring with its progress (Downloading, Installing,
  Verifying, Download stopped). When a game finishes while you're elsewhere, the ring turns green
  and says **Ready to play** until you open Downloads.
- **Settings is a glass sheet with sections.** Sections are on the left, their options on the
  right, and Quit (or Restart and Shut down on AzrakOS) sits under the sections.
- **No more pop-ups.** Messages show where you pressed: on the Settings row, under a game's
  buttons on Home and in its Game Hub, or on a download's row. A problem with a Library card
  opens that game's Game Hub, so you can read it there.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
