A Library of covers: games with only a name now come up when you search for them.

## Changed
- **No more name-only cards while browsing.** A game with no picture yet (often a brand-new
  upload) no longer shows as a blank card among the covers. It's still there: search for it by
  name and it comes up. As soon as its picture arrives, it shows up in the Library again by
  itself.
- **Your games always show.** A game you've installed or are downloading stays in the Library,
  cover or not.
- The game counts on the filters, the Library and the Home screen count the games shown.
- When a game has several releases, its card uses one that has a picture.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
