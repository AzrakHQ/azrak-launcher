A more complete launcher: download a release, install it when you're ready, and keep your
Library tidy.

## Added
- **Background downloads:** review a release's files and size before starting. Pause, resume
	or cancel from **Downloads** (`Ctrl+D`) while you keep browsing.
- **Download → Install → Play:** install a completed download with a separate confirmation.
	Existing games aren't overwritten, original downloads are kept, and nothing launches itself.
- **Seeding:** completed downloads share by default while the launcher is open, capped at
	128 KiB/s total. Turn off **Seed completed downloads** in Settings, or choose **Stop seeding**
	for one transfer. Closing the launcher stops traffic; reopening doesn't resume it automatically.

## Improved
- **Duplicate cards:** the Library shows one card per game, without losing any of the 614
	English catalog releases. Switch versions and regions in the Game Hub.
- **Library density:** choose **Comfortable** or **Compact**. The choice is remembered,
	smaller windows stay readable, and changing density keeps your place.
- **Filters and sorting:** combine installed/compatibility filters with genre and search.
	The sort menu now shows all seven choices.
- **Card details:** titles get two lines, download size is easier to read, and seeders/leechers
	are green/red. The snapshot date appears once above the grid, not on every card.
- **Welcome screen:** a new white/electric-blue P5 emblem and a quieter splash screen.

## Notes
- Peer counts are dated website snapshots, not live totals. Catalog reload still reads local
	JSON; online per-game refresh isn't included yet.
- Archive installation needs system libarchive. Password-protected archives, PKG decryption
	and update/DLC merging aren't supported. Validation checks structure, not authenticity or
	every archive checksum.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
