Releases that ship as an exFAT disk image now install.

## Fixed
- **exFAT releases:** about one in nine catalog releases ships as a single `.exfat` disk image
	instead of a folder or an archive. Installing one failed with "No valid extracted game found".
	The launcher now reads the image and installs the game inside it, with the same checks as
	archives. The downloaded image is left unchanged, so it keeps seeding.

If an install failed this way, open **Downloads** (`Ctrl+D`) and choose **Retry install**.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
