Compatibility tags you can trust on Linux, and an easy way to share how your games run.

## Improved
- **Linux-first compatibility tags:** a game tested on Linux now shows its Linux result. Before,
	the tag was the best result from any OS, so a Windows "In-game" could hide a Linux
	"Doesn't boot". Results from Windows are marked, for example **Win · In-game** on Library covers.
- **Game Hub:** shows the Linux and Windows results separately.
- **Filters and sorting:** the filter is now **In-game on Linux** and counts only games confirmed
	on Linux. The compatibility sort lists Linux results first.

## Added
- **Report how it runs:** in an installed game's **Options** menu. It opens KytyPS5's report form
	already filled in with the game, KytyPS5 version, your PC's details and the end of the
	emulator log, and opens the folder with the full log so you can attach it. You choose the
	result and submit; nothing is sent without you.
- **About:** the end of **Settings** shows the launcher version and the Slint attribution.
- **Third-party notices:** the download now includes `THIRD-PARTY-NOTICES.md` and a `licenses`
	folder with the licenses of the software the launcher is built with.

## Notes
- Linux reports are still rare: most games have only Windows results or none yet. Every report
	you send helps everyone. Sending one needs a free GitHub account.
- The README is now a short guide for players. Build and internals documentation moved to
	`docs/DEVELOPMENT.md`.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
