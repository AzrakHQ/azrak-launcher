A game's page stays the same game on every platform, clearer platform tags, and fixes for
one card per game.

## Improved
- **The game's details on every platform's page.** Switching a game's page from PS4 to PC
  (or back) keeps its About, rating, age rating, screenshots and trailer. What differs by
  version stays its own: how it plays on this PC, size, availability, release and store page.
- **Platform tags under each card.** A card's platforms are small coloured tags next to its
  size (PS5 white, PS4 blue, PC green), and the cover is clean again.
- **Store pages.** Each version links to its store: the PlayStation Store for PS5 and PS4,
  Steam for PC. The forum topic link is gone.
- **Best for this PC** stays on the same platform while you look through its releases.

## Fixed
- Two different games with the same name could end up on one card when a release had no
  date (Doom and Doom 2016, Prey 2006 and 2017).
- A Windows game with a good ProtonDB rating showed as playable on a PC without Proton or Wine.
  It now says **Needs Proton or Wine**.
- The highlighted card in the Library could jump to another game when the list refreshed in
  the background, after an install, or when this PC's check finished. It stays put now, also
  under an open game page.
- A game's About could mix the text of two different editions.
- A tile and the game's page could describe a game differently.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
