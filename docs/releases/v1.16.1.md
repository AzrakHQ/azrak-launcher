A tidier Library: no PS5 games you can't install, and PC game names without version clutter.

## Improved
- **No more PS5 games you can't install:** PS5 releases packed as PKG packages are no longer
  listed. The launcher can't install them, so 47 games had nothing but a "can't be installed"
  message (and often no cover). A PKG release you were already downloading stays.
- **Clean PC game names:** names no longer carry version numbers, builds, dates or "+ DLC"
  from the release title ("Mafia III: Definitive Edition", not "Mafia III: Definitive Edition
  (v.build 25654741 (08.10.2026))"). Releases of the same game now group into one card.
- **More PC games get their artwork:** games that weren't matched to their Steam page because
  of those names (Mafia III, Baldur's Gate II and others) are looked up again over the next few
  days.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
