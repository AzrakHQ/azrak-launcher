Hide your IP address with your own VPN, see whether a game will run on your PC before
downloading it, and get new releases without waiting for an app update.

## New
- **Download only through a VPN** (Settings → Downloads): downloads and sharing use only your
  VPN. If it disconnects, they pause and carry on when it's back, so your real address is never
  used. Bring your own VPN (WireGuard or OpenVPN): connect it with its app, or choose
  **Settings → Your VPN** and pick the `.conf` or `.ovpn` file from your provider.
- **Will it run on this PC?** Each Game Hub says **Should run well**, **May run slowly** (with
  the reason, e.g. integrated graphics) or **Won't start** (e.g. a graphics card without the
  Vulkan features the emulator needs), and warns when there's no room for the download. The
  download dialog warns before you download a game this PC can't run. See your processor,
  memory and graphics card in **Settings → This PC**.
- **New releases arrive by themselves:** the game list is updated daily with new releases,
  re-uploads and seeder counts. The launcher checks every 6 hours (or **Settings → Advanced →
  Check for new releases**) and says how many new releases arrived.

## Improved
- Settings and dialogs stay readable on small windows and screens.
- The install dialog says which files each console's games install from (PS4 PKG packages
  are supported; PS5 PKG packages aren't).
- Groundwork for a lighter PS5 Launcher OS without a desktop: on it, Settings gets a System
  section (Wi-Fi, controller pairing, sound output, updates, restart and shut down). Not
  released yet.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/MohamedAliRashad/ps5-launcher/releases/latest/download/ps5-launcher-linux-x86_64.tar.gz | tar xz && ./ps5-launcher-linux-x86_64/install.sh
```
