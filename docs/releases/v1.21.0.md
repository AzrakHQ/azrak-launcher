Every game's page now opens on its newest version, and tells you when the one you're looking
at is older, so you don't spend hours downloading something that's already out of date.

## New
- **The newest version first.** When a game has several releases on a platform, its page
  opens on the newest one that people are sharing, instead of whichever was uploaded first.
- **Newest and older versions are labelled.** The release picker says **newest version** or
  **older version** next to each release of the same game, edition and region.
- **A note before you download something old.** An older release says so in amber under
  Download, with the version you'd get and the newer one you can pick instead:
  "Older version 1.12: 1.19 is under Choose another release". If the newer one has nobody
  sharing it right now, the note says that too.

Versions are only compared where it makes sense: the same edition (a Gold Edition or a
Director's Cut numbers its own patches), the same region, a native Linux port apart from a
Windows game under Wine, and never a firmware, backport or tool version written beside the
game's. When a release's version can't be read for sure, it's never called older.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
