Hundreds more PC games now install, and the Library stops offering the ones that can't.

## New
- **Self-extracting installers install.** Releases shipped as a single `.run` or `.sh` installer
  (a YAD Simple Installer: Balatro, most Linux releases from LinuxRulez and the Wine repacks
  named `…_wine_repack`) are unpacked like any archive, whatever they're compressed with. Their
  scripts never run; Play starts the game's own start script.
- **Every RAR installs.** RAR archives are now read by RARLAB's own decoder, built in. Archives
  packed with a large dictionary (common on RuTracker) used to fail with "Nothing in this release
  can start the game".
- **Releases that can't be installed aren't offered.** The Library leaves out PC releases whose
  files show Azrak can't install them: Debian packages, CrossOver bottles, PlayOnLinux packages
  and disc images. One you've already downloaded stays.
- **No wasted downloads.** If a release turns out not to be installable once its file list
  arrives, the download stops before any of it is downloaded and tells you why, so you can pick
  another release of the game.

Also: Wine packs made with Wine Launcher (`extract.sh` beside `static.tar.gz`) install, and
`.txz` archives are unpacked.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```

A download that failed to install before this update: open Downloads and choose **Retry install**.
