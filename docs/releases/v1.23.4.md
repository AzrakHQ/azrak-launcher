PC games with a subtitle show as themselves, and every game page says which release you're getting.

## Fixed
- **PC games no longer show up as an older game in their series.** Some releases were shown as
  the game they follow, with its name, cover and description: Splinter Cell: Blacklist as the
  first Splinter Cell, Assassin's Creed Valhalla as the first Assassin's Creed, Kingdom Come:
  Deliverance, Sniper Elite: Resistance and Life is Strange: Reunion as other games. The catalog
  now keeps a game's subtitle when it looks it up on Steam, and those releases are looked up
  again with the next catalog update.

## Improved
- **The game page shows the release's own name** under the title when it says more than the
  title does, like "Release: Tom Clancy's Splinter Cell: Blacklist Deluxe Edition" or which
  edition you're downloading.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
