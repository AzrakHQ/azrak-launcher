A friendlier launcher, and everything the new AzrakOS needs: try it from a USB stick, install
it from the launcher, and set up Wi-Fi with just a controller.

## New on AzrakOS
- **Try AzrakOS before installing it.** The new AzrakOS USB stick starts AzrakOS itself, and
  nothing on the PC changes. Choose **Try AzrakOS** to play around, or **Install on this PC**.
- **Install from the launcher**, with a controller: pick the disk, check, install, restart.
  It picks a disk without Windows on it first, says plainly when Windows would be erased,
  shows the real progress, and lists the Secure Boot steps you'll need after the restart.
- **Join Wi-Fi with a controller.** Choosing a secured network opens a card with an
  on-screen keyboard (a keyboard still types straight in). A wrong password says so and keeps
  what you typed. Networks show signal bars and a lock; the strongest six come first.
- **Restart and Shut down ask first**, so a stray press doesn't turn the console off
  mid-download.
- Pairing a controller counts down while it searches, and paired devices say what pressing
  them does. Changing the sound output says where the sound goes now.
- The launcher can't be closed by accident any more on AzrakOS (it's the whole screen there).

## Improved
- **Plain words everywhere:** games show **Availability: Good / Low / None** instead of
  seeder counts, the Game Hub gives one verdict on whether a game plays on this PC (it no
  longer says "Should run well" next to a report that it stops at the logos), and the start
  screen and notices talk about "PS5 support" and "game pictures" instead of emulator names.
- **Download says what it will do:** the size, the folder it goes to, then "press Install",
  in amber when the disk is short of space.
- **No games yet?** Home now offers **Browse games** first, on Azrak's own backdrop.
- The Downloads sheet is easier to read, and the Library keeps its cards in place while
  artwork arrives.
- Bigger text, icons and clock, readable from the sofa.

## Fixed
- **Settings → Internet:** choosing a secured Wi-Fi network did nothing (no password field).
- Typing to search in the Library put the first letter last ("olverinew").

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
