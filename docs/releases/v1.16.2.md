## Improved
- **New releases aren't blank any more:** releases added by the daily update had no cover,
  genre or details until their pages were read. They now take their game's details (cover,
  genre, developer, release date) from another release of the same game.
- **One "In-game" filter, for Linux:** the launcher runs on Linux, so the Library's **In-game**
  filter and the tags on covers now count only results confirmed on Linux. Results from Windows
  still show in the Game Hub, marked as untested on Linux.
- A game without artwork no longer shows the previous game's background.
