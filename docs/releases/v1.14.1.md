A safety update for installing PS4 PKG releases, plus fixes from a review of v1.14.0.

## Fixed
- **PKG installs are contained:** the PKG extractor now runs in a sandbox where it can only write
	inside the folder it's unpacking into, so a damaged or malicious package can't touch anything
	else on your PC. This needs Linux 5.13 or newer; on older systems PKG releases aren't installed.
- **No half-unpacked games:** if the extractor crashes or stops early, the install fails with a
	message instead of adding an incomplete game to your Library.
- **Your DLC is safe:** DLC from a PKG release is only put in place after the game installs, and
	never replaces an add-on you already have. A failed or cancelled install leaves your add-ons
	as they were.
- **Game updates are kept:** when a PS4 release ships its update next to the game (as a folder or
	inside an archive), the update is now installed with it, as it already was for PKG releases.
- **Automatic updates respect your choice:** if you had turned automatic updates off before
	v1.14.0, shadPS4 no longer installs or updates by itself; **Settings → Update automatically**
	shows Off and means it.
- **Small windows:** the Library's game count no longer covers the **PS4 games only** filter on
	narrow screens, and genre chips scrolled off the left edge fade out instead of being cut.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
