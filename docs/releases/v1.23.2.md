## Improved
- **A dot when an update is ready.** While an update for the launcher or KytyPS5 is ready, or
  installed and waiting for a restart, the gear in the top bar has an amber dot. In Settings,
  **Updates** has one too, beside "1 ready" or "Restart". Both go once the update is done.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
