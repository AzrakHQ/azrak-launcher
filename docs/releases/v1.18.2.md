## Improved
- **A much faster first start.** It used to wait for every game's pictures and details,
  every cover and the PS5 emulator, which could take 8 minutes or more. Now it only waits
  for the game list and the Home screen, a few seconds; everything else keeps coming in the
  background while you look around (the status line shows it). On the AzrakOS USB stick,
  where every start is a first start, trying AzrakOS is now quick.
- The start screen's steps are just **Game list** and **Your Home screen**.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
