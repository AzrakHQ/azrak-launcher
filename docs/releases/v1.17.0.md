**Azrak Launcher** gets a new logo and a new home.

## New
- **Azrak Launcher** (أزرق, "blue"), with a new logo, now lives at
  [github.com/AzrakHQ/azrak-launcher](https://github.com/AzrakHQ/azrak-launcher). The PC edition
  is **AzrakOS** ([github.com/AzrakHQ/azrak-os](https://github.com/AzrakHQ/azrak-os)).
- Settings, emulators, saves, Wine prefixes and caches live in `~/.config/azrak`,
  `~/.local/share/azrak` and `~/.cache/azrak`; games and downloads in `~/Games/Azrak` and
  `~/Downloads/Azrak`. The command is `azrak`.

## Improved
- **PS4 exclusives in the Library:** God of War III Remastered and 140 more PS4 exclusives
  that were missing from the game list are in (they arrived with the game list's update, no
  launcher update needed).

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
