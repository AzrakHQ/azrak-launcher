PC games join the Library, covers that were blank get artwork, and the PS5 emulator installs
again when its newest release has no Linux build yet.

## New
- **PC games:** native Linux games and Windows games packed with Wine are in the Library, next
  to PS5 and PS4 games (filter with **PC games only**). Each one has its Steam page: description,
  screenshots, trailer and artwork, with its ProtonDB rating for Windows games, or **Native
  game**. Download and install them like any other game. Play starts them straight away; a
  Windows `.exe` runs through Proton (with [umu-launcher](https://github.com/Open-Wine-Components/umu-launcher))
  or Wine, whichever is installed. If the launcher picked the wrong file to start, choose
  **Options → Start with …**.

## Improved
- **Artwork for new releases:** games added by the daily update had blank covers. They now
  show Steam's artwork, and a game with no artwork anywhere shows its name instead of loading
  forever.
- No RAWG API key to set up any more: artwork needs no account.
- **KytyPS5 installs again:** when its newest release had no Linux build yet, first-time setup
  failed with "this release has no Linux build yet". The launcher now installs the newest
  release that has one.
- Downloads that fail because the network isn't up yet (the emulators, the game list, covers)
  are retried as soon as it is.
- **This PC:** older NVIDIA cards (GTX 600 to 1000 series) on the open-source NVK driver show
  **May run slowly**, since that driver keeps them at a low clock.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
