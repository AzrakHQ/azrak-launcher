Proper covers in the Library: no more wide strips or blank cards for games we have pictures for.

## Fixed
- **Real covers for new Steam games.** Steam stores the pictures of newer games somewhere
  the game list didn't look, so about 500 games showed a wide banner squeezed onto their card
  (Stupid Never Dies, Moss: The Forgotten Relic, Call of Duty: Modern Warfare 4…). They now
  show their proper portrait cover. This part comes with the game list, so it reaches every
  launcher version.
- **No blank card when another release has pictures.** A game with no pictures of its own,
  like Bloodborne packed for PC, now shows the pictures of another release of the same game,
  from any console.
- A game with only wide artwork on Steam shows the release's own cover first.

A few brand-new console uploads still show their name until their details are read; they
get their cover then.

## Update
Launchers on v1.3.0 or later update themselves if automatic updates are enabled. Otherwise:

```bash
curl -fsSL https://github.com/AzrakHQ/azrak-launcher/releases/latest/download/azrak-linux-x86_64.tar.gz | tar xz && ./azrak-linux-x86_64/install.sh
```
